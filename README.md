
# 🌌 智能天体识别与科普助手

> **"让每个人都拥有一个口袋里的 AI 天文导游"**  
> 初中生 AI 创新创业项目 | 鲲鹏少年院 | 作者：陈思宇

---

## 📖 项目简介

拍一张夜空照片，AI 秒级识别天体，用大白话讲给你听。

本项目面向观星入门人群——初级天文爱好者、观星游客、对天文感兴趣的青少年。用户只需用手机对着夜空拍一张照片，系统即可借助 AI 图像识别技术自动标注出天体（恒星、星座、行星等），并以通俗易懂、简短有趣的方式科普相关知识。

**核心原则：AI 只做转述，不做创作。** 建立权威天文知识库（中国天文学会、NASA），保证每条科普源头正确、表达亲民。

---

## ✨ 功能亮点

| 亮点 | 说明 |
|------|------|
| 🌟 **AI 拍照识星** | 一键拍照 / 上传照片，秒级识别天体 |
| 🔄 **双模式识别引擎** | 端侧快速识别（离线可用）+ 云端精准校准（联网增强） |
| 📚 **权威知识库** | 引用中国天文学会、NASA 等权威源，AI 只转述不编造 |
| 📡 **离线也能用** | 本地预置亮星数据，无网络也能基础识星 |
| 🎯 **Plate Solving** | 星点位置反算拍摄天区坐标，精确定位天体 |

---

## 🛠️ 技术栈

- **纯前端实现**：HTML5 + CSS3 + 原生 JavaScript
- **零框架依赖**：无 React/Vue/jQuery，极致轻量
- **Canvas 动画**：200+ 粒子动态星空背景
- **响应式设计**：适配桌面端、平板端、手机端

## 🚀 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/Hqinxuan/Kunpeng_Star.git
   ```

2. 双击 `index.html` 即可在浏览器中运行（或通过任意静态服务器托管）

3. 上传一张夜空/天体图片 → 点击"开始识星" → 查看 AI 识别结果与科普知识
